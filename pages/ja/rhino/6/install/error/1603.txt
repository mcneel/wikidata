====インストールエラー 1603 - Rhino 6、Rhino 7、Rhino 8====

インストール中の致命的なエラー（-2147023293）

> **要約:** //インストールエラー 1603 の修正方法//

=====問題=====
様々な問題がエラー1603の原因になり得ます。以下の全ての手順に従って修復を試みてください。

=====回答=====
**手順1: Windows Updates の実行**
  - [[https://support.microsoft.com/windows/deployment/updates-lifecycle/install-windows-updates/|Windows Update サービス]]にアクセスし、実行します。
  - インストールする重要な更新プログラムがある場合は、**今すぐ更新** をクリックして更新プログラムをインストールしてください。このプロセスには時間がかかることがあります。

\\
**手順2: .NET Framework 4.8 のインストール**
  - [[https://dotnet.microsoft.com/download/dotnet-framework/net48|.NET Framework 4.8 インストーラー]]をダウンロードし、実行します。
  - エラーが表示されなくなった場合は手順4に進みます。
  - Microsoft .NET インストーラーがエラーを表示する場合は: 
    - エラーを書き留め、手順3に進みます。

\\
**手順3: .NET Framework 4.8 の修復**
  - [[https://learn.microsoft.com/dotnet/framework/install/repair|.Net Framework Repair Tool]] をダウンロードし、実行します。
  - Microsoft .NET Framework Repair Tool がエラーを表示する場合は: 
    - エラーを書き留めます。
    - 下の**それでもうまく行かない場合**の手順に進みます。

\\
**手順4: Rhinoをインストール**
  - **Windowsエクスプローラー**を開きます。
  - [[https://www.rhino3d.com/download/rhino-for-windows/8/latest/|Rhino 8]]、[[https://www.rhino3d.com/download/rhino/7/latest|Rhino 7]]、または [[https://www.rhino3d.com/download/archive/rhino/6/latest|Rhino 6]] の最新のインストーラーをダウンロードします。
  - ダウンロードしたファイルを実行し、インストールのプロセスを開始します。
  - もしインストーラーがうまく動作しなかった場合は、ログファイルのコピーをデスクトップに保存します。
\\
**それでもうまくいかない場合**

それはお困りでしょう。申し訳ありません。恐れ入りますが、手順3のログファイルをメールで tech@mcneel.com（米国）またはsupport@rhino3d.co.jp（日本のサポート） までお送りいただけますか。よろしくお願いします。
