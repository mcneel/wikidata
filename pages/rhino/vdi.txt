====== Does Rhino support VDI? ======

Rhino 8 and later supports a number of VDI (Virtual Desktop Infrastructure) systems:

  * Amazon AppStream
  * Amazon Workspaces,
  * Citrix XCenApp
  * Citrix XenDesktop
  * Cloudalize
  * Itopia
  * Nutanix Frame
  * Vagon.io

Rhino is officially not supported on AWS EC2, though you might be able to get it to run if you use Remote Desktop to access it. Getting good display performance over RDP is challenging, even with proper NVIDIA cards. We can't help get that working.

In summary, Rhino will run in the “supported” VDI environments, but we cannot help with setting it up for better graphics performance, however.

==== Rhino.Compute ====

We have a list of supported VDI environments is that in the beginning of Rhino 7, with the creation of [[https://developer.rhino3d.com/guides/compute/|Rhino.Compute]].

We required Rhino to use Core-Hour Billing for licensing when we detected that it was running on Windows Server. Many of these VDI environments are detected as Windows Server and of course users want to use regular seat-based licenses (i.e. license keys in standalone mode, LAN Zoo, or Cloud Zoo).

==== Graphics Performance ====
Our general advice is for users to try Rhino in these environments and see if it works for you. 
If there are licensing problems, please email tech@mcneel.com. 

Unfortunately, we can not help with performance problems as we don’t have the general knowledge for configuring graphics in virtual environments.
It gets very complicated and solutions are platforms specific and generally require specific configuration.
