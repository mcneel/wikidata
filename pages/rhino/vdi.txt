
====== Does Rhino support VDI? ======
Rhino 8 and later supports a number of VDI (Virtual Desktop Infrastructure) systems:
  * Amazon AppStream
  * Amazon WorkSpaces
  * Citrix XenApp
  * Citrix XenDesktop
  * Cloudalize
  * Itopia
  * Nutanix Frame
  * Vagon.io

Rhino is not officially supported on AWS EC2, though you may be able to get it running by using Remote Desktop to access it. Getting good display performance over RDP is challenging, even with proper NVIDIA cards, and this is not something we can help you configure.

In summary: Rhino will run in the "supported" VDI environments listed above, but we cannot help with tuning graphics performance in any of them.

==== Rhino.Compute ====
This list of supported VDI environments dates back to the beginning of Rhino 7, around the same time [[https://developer.rhino3d.com/guides/compute/|Rhino.Compute]] was introduced.

At that time, we required Rhino to use Core-Hour Billing whenever it detected it was running on Windows Server. Since many VDI environments are themselves detected as Windows Server, this caused problems for users who wanted to use standard seat-based licensing instead (license keys in standalone mode, LAN Zoo, or Cloud Zoo).

==== Graphics Performance ====
Our general advice is to try Rhino in these environments and see whether it works for you.

  * If you run into licensing problems, email tech@mcneel.com.
  * Unfortunately, we can't help troubleshoot performance problems — we don't have the specialized knowledge needed to configure graphics in virtual environments. This gets complicated quickly, and solutions tend to be platform-specific with their own particular configuration requirements.
